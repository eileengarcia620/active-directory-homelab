# Active Directory Home Lab

A self-directed home lab built to practice enterprise systems administration skills — specifically Windows Server, Active Directory, and common break/fix troubleshooting scenarios IT professionals deal with day to day.

## Why I Built This

Practicing enterprise systems administration and troubleshooting skills for entry-level IT roles.

## Environment

- **Virtualization:** Oracle VirtualBox
- **Domain Controller:** Windows Server 2019 (Evaluation, Desktop Experience)
- **Client:** Windows 10/11, joined to the domain
- **Networking:** Internal network configured between DC and client

## What's Documented Here

Each scenario below follows the same format: the setup, what was broken (intentionally), how I diagnosed it, and how I fixed it, with screenshots.

## Skills Demonstrated

- Windows Server installation and Active Directory Domain Services configuration
- User, group, and OU management
- Systematic troubleshooting methodology (identify → isolate → resolve → document)
- DNS, account policy, and NTFS/share permission fundamentals
- Writing clear documentation that both technical and non-technical people can follow
